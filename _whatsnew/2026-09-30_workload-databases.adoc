=== Suporte a vários sistemas de arquivos por uma única instância

O Workload Factory for Databases oferece suporte a vários sistemas de arquivos por instância única do Microsoft SQL Server. Você pode registrar vários sistemas de arquivos em uma instância do SQL Server e corrigir um problema de configuração em vários sistemas de arquivos em uma instância do SQL Server ao mesmo tempo.
